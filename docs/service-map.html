02Четыре потока

  1. Заявка. Архитектор выбирает тему или материал → шторка → sendData в бот → бот создаёт задачу Pyrus (12 полей, фото комментарием) → карточка с кнопками в чат отдела → заявителю «принята, №…».
  2. Статус. Отдел нажимает кнопку в чате → бот переводит колонку доски, при «Готово»/«Отклонена» закрывает задачу → уведомление автору и подписчикам; статус виден в кабинете и ленте.
  3. Уточнение и приёмка. «Уточнить» в чате → вопрос комментарием → заявителю в чат с ботом → ответ из кабинета → задача снова «В работе». После «Готово» заявитель принимает или возвращает с замечаниями (переоткрытие).
  4. Лента и подписка. Сервер Mini App читает реестр доски, показывает задачи по колонкам с обложками; «Следить» пишет в задачу комментарий «Подписка: tg:id», бот шлёт подписчикам изменения.
